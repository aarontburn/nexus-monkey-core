# Nexus Monkey Core

A internal module for [Nexus](https://github.com/aarontburn/nexus-core). Used to "embed" native Windows applications into Nexus.

# Automatic Installation
1. Ensure you have [Nexus](https://github.com/aarontburn/nexus-core) installed.
2. Navigate to [Monkey Core on the Nexus Marketplace](https://www.nexus-app.net/marketplace/6843548c98a85fc73a702330)
   -   https://www.nexus-app.net/marketplace/6843548c98a85fc73a702330
3. Press the "Install to Nexus" button

## Manual Installation
1. Download the latest release `.zip`. 
2. In Nexus, navigate to **Settings** > **Import Module**
3. Select the downloaded `.zip` file to install.
